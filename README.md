# Laxman Phool Bhandar — Floral Business Website

A responsive Next.js + TypeScript starter for a flower and decoration business. Includes a home page, services catalog, visual gallery, and inquiry form that opens WhatsApp with customer details prefilled. Supabase persistence is optional.

## Requirements
- Node.js 20.9+ recommended
- npm

## Run locally

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open http://localhost:3000.

## Important setup before launch

1. Open `.env.local` and set `NEXT_PUBLIC_WHATSAPP_NUMBER` to the business WhatsApp number, including country code and digits only. For example, `919876543210` (replace with the real number).
2. Update the service pricing and text in `lib/data.ts`. Current prices are sample starting prices and should be verified by the business before publishing.
3. Replace the inspiration photos in `lib/data.ts` and the homepage with the client's own photos where possible. Remote demo photos use Unsplash URLs.
4. Update the business address, opening hours, phone number, and social links once confirmed.

## Optional Supabase booking storage

The form sends the inquiry to WhatsApp. If Supabase is configured, it also attempts to insert a booking record into a `booking_requests` table.

Create a table in Supabase SQL Editor:

```sql
create table public.booking_requests (
  id bigint generated by default as identity primary key,
  customer_name text not null,
  phone text not null,
  email text,
  service text not null,
  event_date date,
  venue text,
  budget text,
  details text,
  status text not null default 'new',
  created_at timestamptz not null default now()
);

alter table public.booking_requests enable row level security;

-- Allows anonymous form submissions only. Do not add public SELECT/UPDATE/DELETE policies.
create policy "Allow public booking submissions"
on public.booking_requests for insert to anon
with check (true);
```

Then add your Supabase project URL and anon/public key to `.env.local`:

```env
NEXT_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
NEXT_PUBLIC_WHATSAPP_NUMBER=91XXXXXXXXXX
```

Never put a Supabase `service_role` key or any other secret in a `NEXT_PUBLIC_` variable. For a production launch, add server-side validation and abuse protection (rate limiting / CAPTCHA) to the booking submission endpoint. This starter uses the browser Supabase client for the optional insert and therefore the database policy must be configured carefully.
